{{ _('4.2 Core Concepts') }}

{% trans %}The AuScope Instrument Registry centres around four core concepts available directly from the header navigation menu. These core registries combine to form an interconnected network of metadata. This network structure delivers maximum data provenance, precise citation tracking, and complete tracking transparency.{% endtrans %}

{{ _('Each entity represents a specific type of asset, stakeholder, or controlled classification within the registry:') }}

{{ _('Instruments') }}

{{ _('Individual physical devices or distinct pieces of scientific equipment. This catalogue tracks physical assets and captures structural fields, including unique persistent identifiers, manufacturers, owners, physical locations, operational lifecycle states, and measured variables.') }}

{{ _('Platforms') }}

{{ _('Grouped profiles detailing configurations of multiple instruments working together as a singular deployment system. Platforms allow geoscientists to describe how individual instruments are combined and arranged across different field surveys, arrays, or configurations.') }}

{{ _('Parties') }}

{{ _('The administrative directory of stakeholders associated with instrument lifecycles. This module manages records for equipment manufacturers, funding institutions, administrative organisations, and individual technical contacts, with organisation profiles dynamically integrated with verified global research IDs via the ROR API.') }}

{{ _('Taxonomies') }}

{{ _('Controlled vocabulary indexes that establish system-wide data consistency. Taxonomies provide hierarchical dictionaries for filtering and classifying hardware by scientific sector, instrument types, and measured environmental variables.') }}
