{{ _('Assembling the instrument array') }}

{% trans %}A platform configuration is defined by linking a collection of individual instruments that work together as a unified measurement system. Users assemble this array in the Related Instruments panel using the autocomplete search bar to query existing assets by title, model, or serial number. Once selected, each connected device is explicitly logged and displayed as an active "Component" of the broader platform layout. This explicit relationship list ensures detailed configuration traceability and preserves data provenance across multi-device geoscience surveys.{% endtrans %}
